# Forest-inspired product-name research

Checked: 2026-07-24

Historical naming research. The product name was subsequently settled as
**Silvic**.

## Recommendation

At the time of this initial scan, **Branchkeeper** was the leading candidate.

It preserves the “person who looks after the forest” idea while speaking directly
to Git branches. In preliminary checks, no exact competing developer product,
GitHub repository, npm package, crates.io package, Homebrew formula, or Mac App
Store product was found. `branchkeeper.com`, `branchkeeper.dev`, and
`branchkeeper.app` were reported as available by a live domain check.

This is preliminary product-name research, not legal trademark clearance.

## Why not the literal word?

The ordinary English word for German “Förster” is **forester**. In this category,
however, it has a serious collision: Paper Compute’s **Paper Forest** uses a
`forester` CLI to create and manage “groves” for parallel AI-agent work. That is
too close to this app’s core model.

Sources:

- https://papercompute.com/blog/paper-forest/
- https://apps.apple.com/ie/app/forester/id1607048411

## Existing working title

**Branchdeck** should not be used publicly. An active product with that exact name
describes itself as “an agentic workspace for managing repos, worktrees, and
coding sessions” and includes worktree creation, Claude Code sessions, PR/CI
status, and parallel autonomous runs.

Source:

- https://github.com/DogaOztuzun/branchdeck

## Ranked shortlist

1. **Branchkeeper** — clearest balance of meaning, memorability, and preliminary
   availability.
2. **Woodreeve** — a real historical English word meaning an overseer or steward
   of a wood. Distinctive, but obscure; `woodreeve.com` is unavailable and an
   unrelated forestry consultancy uses the name.
3. **Silvic** — compact name derived from silviculture. Technically apt, but not
   immediately understandable; `.com` is unavailable.
4. **Forestreeve** — coined, ownable-looking compound with the relevant “reeve”
   root, but visually awkward and not a standard word.
5. **Branch Forester** — explicit and understandable, but long and still likely
   to be confused with Paper Forest’s `forester`.

Dictionary sources for Woodreeve:

- https://www.merriam-webster.com/dictionary/woodreeve
- https://www.collinsdictionary.com/dictionary/english/woodreeve

## Names to avoid

- **Forester** — direct Paper Forest/`forester` category collision and heavy
  general product/brand use.
- **Branchdeck** — exact-name direct competitor.
- **Grove** — multiple worktree/AI-agent tools, including a Mac product.
- **Copse** — AI-agent PR-management and Git-worktree tools.
- **Coppice** — existing macOS productivity app and other software products.
- **Branchwarden** — exact Git branch-auditing and cleanup CLI.
- **Ranger / Forest Ranger** — extremely crowded and suggests patrol/protection
  rather than managing development environments.
- **Arborist** — concerns individual trees and is already crowded.

Selected sources:

- https://www.usegrove.dev/
- https://copse.dev/
- https://coppiceapp.com/
- https://github.com/danjdewhurst/branchwarden

## Naming rationale

The product’s durable concept is broader than Git worktrees: it creates and tends
complete environments for parallel coding agents, then opens them in different
agent harnesses. Therefore, avoid putting `Worktree` in the product name. It is an
implementation primitive, not the long-term category.

Suggested spelling: **Branchkeeper**

Possible positioning:

- “Keep every branch, workspace, and agent in view.”
- “The workspace manager for parallel coding agents.”
