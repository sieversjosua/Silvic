# WorktreePilot brand assets

- `WorktreePilot-AppIcon-Generated.png` is the original ImageGen output.
- `WorktreePilot-AppIcon-1024.png` is the masked 1024 px production master.
- `../WorktreePilot.icns` is the macOS icon bundle used by the release app.

The icon intentionally shares OctaTrack's warm, faceted visual language while
using a branching worktree glyph as WorktreePilot's own product symbol.
