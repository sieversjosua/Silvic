# Branchdeck brand assets

- `Branchdeck-AppIcon-Generated.png` is the original ImageGen output.
- `Branchdeck-AppIcon-1024.png` is the masked 1024 px production master.
- `../Branchdeck.icns` is the macOS icon bundle used by the release app.

The icon intentionally shares OctaTrack's warm, faceted visual language while
using a branching worktree glyph as Branchdeck's own product symbol.
