# Silvic brand assets

- `Silvic-AppIcon-Generated.png` is the original ImageGen output.
- `Silvic-AppIcon-1024.png` is the masked 1024 px production master.
- `../Silvic.icns` is the macOS icon bundle used by the release app.
- `Silvic-Electron-AppIcon-Generated.png` is the raster concept approved for
  the Electron app.
- `Silvic-Electron-AppIcon.svg` is the canonical vector master, produced with
  Fal's Recraft vectorizer and normalized to Silvic's `#1f6b4a` accent.
- `Silvic-Electron-AppIcon-1024.png` is the production render of that SVG.
- `../Silvic-Electron.icns` is generated from the vector master and used by
  the Electron release.

The icon intentionally shares OctaTrack's warm, faceted visual language while
using a branching workspace glyph as Silvic's own product symbol.
